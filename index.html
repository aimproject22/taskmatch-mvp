DEPLOYMENT

계속 수정하며 관리하는 추천 방식

추천

GitHub Pages

현재 프로젝트처럼 HTML/CSS/JS 중심의 정적 MVP를 한 저장소에서 관리하기 좋습니다. GitHub에 push하면 Pages 주소에서 바로 공유할 수 있습니다.

  1. GitHub 저장소 생성
  2. 이 폴더 전체 push
  3. Settings → Pages → Deploy from branch
  4. Branch는 main, folder는 root 선택
확장형

Vercel

나중에 React, Next.js, API, 서버 기능이 붙을 가능성이 크다면 Vercel이 좋습니다. 지금 구조도 바로 올릴 수 있지만, 현재 단계에서는 GitHub Pages가 더 단순합니다.

  1. Vercel에서 GitHub 저장소 Import
  2. Framework Preset은 Other
  3. Build Command는 비워두기
  4. Output Directory는 ./ 선택
